tovo — start timer

Select text on any page, right-click, and choose Start tovo timer. The selection becomes the task title — or, if an open task already has that exact title, the timer starts on that one.

In tovo: Settings → Connections → Access keys, scope capture only. That scope can create tasks and start the timer, but cannot read anything.
  1. Edge will ask for permission to reach the tovo address — allow it.
  2. The key is kept only in this browser profile (not synced).
